# play-store-mcp

MCP server for Google Play Developer API (upload AAB, listing, review, rollout).

## Tools
- `auth`, `upload_aab`, `upload_listing`, `upload_screenshot`, `get_review_status`, `list_rejections`, `submit_for_review`, `rollout_staged`, `get_stats`

## Install
```bash
pip install -e ./mcp-servers/play-store-mcp
```
