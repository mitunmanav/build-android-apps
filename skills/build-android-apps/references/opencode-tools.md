# OpenCode Tool Mapping

| Action skills request | OpenCode equivalent |
|---|---|
| Read a file | `read` |
| Create / edit / delete a file | `apply_patch` |
| Run a shell command | `bash` |
| Search file contents / find files | `grep`, `glob` |
| Fetch a URL | `webfetch` |
| Invoke a skill | `skill` tool |
| Dispatch a subagent | `task` with `subagent_type: "general"` |
| Create / update todos | `todowrite` |
