# asset-mcp

MCP server generating launcher icons, feature graphics, and screenshots (requires Pillow).

## Tools
- `generate_icon` (5 densities + adaptive)
- `generate_feature_graphic` (1024×500)
- `generate_screenshot` (1080×1920)
- `compose_marketing`

## Install
```bash
pip install -e ./mcp-servers/asset-mcp
```
